# 车辆事故智能分析工具 - 产品需求文档

## 1. 概念与愿景

一款专为车主打造的事故现场处理辅助工具，通过AI视觉分析快速评估车辆损伤程度、自动计算维修成本，并为用户提供清晰的理赔指导。界面采用专业汽车行业的冷静科技感，结合直观的数据可视化，让用户在紧张的交通事故现场也能从容应对。

**核心体验**：上传事故照片 → 智能标注损伤区域 → 获取赔偿参考 → 了解正确处理流程

## 4. 功能与交互

### 4.1 图片上传与分析
- **拖拽上传**：支持拖拽或点击上传
- **多图支持**：可同时上传多张事故照片
- **图片预览**：缩略图切换查看
- **缩放平移**：支持双指缩放、移动查看细节

### 4.2 损伤标注系统
- **画笔工具**：在图片上绘制损伤区域
- **区域类型**：刮擦、凹陷、破裂、变形
- **颜色编码**：
  - 🔴 刮擦 (Scratch)
  - 🟠 凹陷 (Dent)
  - 🔵 破裂 (Crack)
  - 🟣 变形 (Deform)
- **面积计算**：基于像素统计估算实际面积（cm²）

### 4.3 赔偿估算
- **损伤评分**：1-10分损伤严重度
- **维修成本估算**：
  - 轻微刮擦：200-500元
  - 小凹陷：500-1500元
  - 中度损伤：1500-5000元
  - 严重损伤：5000-20000元
- **保险理赔预估**：根据损伤程度给出自付额参考

### 4.4 行动指南
根据事故情况生成个性化步骤：
1. 现场安全确认（拍照记录、移车到安全位置）
2. 信息交换（车牌、联系方式、保险信息）
3. 报案流程（是否需要交警、如何快速报案）
4. 维修指引（推荐方案、注意事项）
5. 理赔指导（材料准备、流程说明）

### 4.5 附近服务查询（输入地址功能）
- **地址输入**：支持手动输入或定位当前位置
- **周边查询**：
  - 最近的维修厂（按评分/距离排序）
  - 保险公司网点
  - 交警大队/快速处理中心
- **一键导航**：调用手机地图应用

### 4.6 新奇附加功能
- **损伤时间线**：记录每次检查的状态变化
- **分享报告**：生成可视化事故报告卡片
- **历史记录**：保存过往分析记录
- **AR测量**（进阶）：使用手机传感器估算实际尺寸

## 5. 组件清单

### ImageUploader
- **默认状态**：虚线边框 + 上传图标 + 提示文字
- **悬停状态**：边框高亮，背景微变
- **拖拽状态**：边框变为实线，背景渐变
- **上传中**：进度条 + 文件名
- **上传完成**：缩略图预览 + 删除按钮

### DamageCanvas
- **工具栏**：画笔、橡皮擦、撤销、重做、清空
- **颜色选择器**：4种损伤类型颜色
- **画布**：支持缩放、平移、标注

### DamageCard
- **布局**：损伤类型图标 + 描述 + 面积 + 预估费用
- **悬停**：轻微上浮 + 阴影加深
- **选中**：边框高亮 + 展开详情

### EstimatePanel
- **总评分**：圆形进度环
- **费用明细**：分项列表 + 总计
- **保险参考**：自付额/总费用对比

### ActionGuide
- **步骤卡片**：序号 + 图标 + 描述
- **当前步骤**：高亮 + 展开详情
- **已完成**：打勾标记 + 灰色文字
- **未完成**：待执行状态

### LocationSearch
- **输入框**：带定位图标
- **搜索结果**：列表 + 距离 + 评分
- **地图预览**：小地图标记

## 6. 技术方案

### 框架选择
- **前端**：React 18 + TypeScript + Vite
- **样式**：Tailwind CSS
- **状态管理**：Zustand
- **图标**：Lucide React
- **地图**：高德地图 Web API / 腾讯地图（备选）

### 核心实现
- **Canvas绑定**：使用原生Canvas API进行绑图绘制
- **图片处理**：FileReader + Canvas像素操作计算面积
- **地理位置**：Navigator.geolocation API
- **本地存储**：localStorage保存历史记录
- **响应式**：Tailwind响应式断点 + 抽屉组件

### 数据结构
```typescript
interface DamageArea {
  id: string;
  type: 'scratch' | 'dent' | 'crack' | 'deform';
  points: { x: number; y: number }[];
  color: string;
  area: number; // 像素面积
  realArea: number; // 估算实际面积 cm²
  severity: number; // 1-10
  estimatedCost: number;
}

interface AccidentReport {
  id: string;
  images: string[];
  damages: DamageArea[];
  totalEstimate: number;
  insuranceInfo: InsuranceEstimate;
  actions: ActionStep[];
  createdAt: Date;
  location?: { lat: number; lng: number; address: string };
}
```

### 赔偿估算算法
- 基于损伤面积和类型计算基础分数
- 参考市场平均维修价格进行估算
- 考虑保险免赔额和赔付比例
